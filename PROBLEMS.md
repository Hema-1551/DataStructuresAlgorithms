## Workflow

1. Read the problem and write down the input, output, constraints, and edge cases.
2. Study only the problem statement and examples before coding.
3. Implement the method without changing its signature.
4. Send the completed file or paste the method for validation.
5. Validation will check compilation, examples, edge cases, and complexity.
6. After it passes, the next numbered problem will be created.

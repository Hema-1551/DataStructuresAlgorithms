# DSA 280: Beginner-Friendly Concept-First Roadmap

A beginner-first roadmap with 30 easy starter problems distributed across all 13 topic phases. The difficulty labels are practical study guidance, not a guarantee of platform difficulty. Solve in order within each category, and do not rush to the next problem until you can explain the invariant and complexity.

## How to Use This Roadmap

For every problem:

1. Understand the input, output, constraints, and two edge cases.
2. Model the data structure or pattern before coding.
3. Attempt the problem for 25-40 minutes without reading a solution.
4. Learn only the key idea if stuck, then close it and reimplement.
5. State the invariant, correctness argument, time complexity, and space complexity.
6. Revisit after 1 day, 1 week, and 1 month.

Suggested pace: 5 problems per week gives 56 weeks. If you are brand new to DSA, repeat each phase's starter problems until the patterns feel natural before moving on.

## Milestones and Depth Checks

- After 30: comfortable with arrays, loops, conditionals, basic strings, and simple math.
- After 80: able to reason about linear scans, hash lookups, and simple invariants.
- After 140: recognizes fixed windows, two-pointer patterns, and basic tree traversals.
- After 200: distinguishes recursion, greedy choice, heap scheduling, and basic graph traversal.
- After 240: defines DP state, transitions, and base cases more confidently.
- After 280: solve 20 previously hard problems from scratch without notes.

## Rules for Real Progress

- Do not count a problem as learned because you watched a solution.
- Reimplement after learning the idea, then explain it aloud without code.
- Keep separate notes for patterns and mistakes.
- For every hard problem, first solve a smaller version or find the nearest medium problem.
- Every fifth problem should be a timed review problem selected from an earlier phase.
